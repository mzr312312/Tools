# 📊 Excel 变更对比工具 (Pro版)

**Excel Compare Pro** 是一款基于 Python (Tkinter + Pandas) 开发的桌面应用程序。它专为财务、运营及数据分析人员设计，用于快速比对两个 Excel 文件（或同一个文件的不同 Sheet）之间的差异。

与普通对比工具不同，它支持**指定主键**（唯一标识），因此即使数据行序被打乱，也能精准识别出**新增**、**删除**和**修改**的内容。

## ✨ 核心功能

* **GUI 图形界面**：无需通过命令行，操作直观简单。
* **多 Sheet 支持**：可以灵活选择“旧文件”和“新文件”中具体的 Sheet 页进行比对（例如：对比 1 月份文件的 "Sheet1" 和 2 月份文件的 "汇总表"）。
* **🔑 复合主键逻辑**：
    * 支持最多 **3 个组合主键**（例如：同时使用“工号”+“姓名”作为唯一标识）。
    * 解决了单一字段无法唯一确定一行数据的问题。
* **智能比对算法**：
    * **新增 (Added)**：新表中有，旧表中没有的行。
    * **删除 (Removed)**：旧表中有，新表中没有的行。
    * **修改 (Modified)**：主键相同，但其他字段内容发生变化的单元格。
* **多线程运行**：比对大数据量文件时界面不会卡死，并配有实时日志窗口。
