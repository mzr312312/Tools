# 🛠️ PDF Toolset Pro (PDF 瑞士军刀)

**PDF Toolset Pro** 是一个基于 Python 和 Streamlit 构建的轻量级 Web 应用程序。它旨在解决 PDF 处理中两个最令人头疼的问题：**按目录结构拆分文件** 和 **批量重构/添加书签**。

该工具经过 NAS 环境优化，适合在本地或私有服务器上部署，拥有直观的 Web 界面。

## ✨ 核心功能

### 1. 🔪 PDF 智能拆分 (Smart Split)
不再需要手动输入“第几页到第几页”。只需告诉程序每一章的“起始页码”，程序会自动计算结束页码并将每一章拆分为独立的 PDF，最后打包为 ZIP 下载。

* **输入格式**：`起始页码 章节标题`
* **逻辑**：自动识别上一章的结束页为下一章起始页的前一页。
* **输出**：自动重命名文件（如 `01_封面.pdf`, `02_第一章.pdf`）。

### 2. 🔖 批量书签编辑器 (Batch Bookmarks)
专为扫描版电子书设计，解决了“PDF 物理页码”与“书本印刷页码”不对应的问题。

* **双区配置**：
    * **前言区**：使用绝对物理页码（适用于封面、目录、前言）。
    * **正文区**：使用逻辑页码 + 自动偏移量（Offset）。
    * *例如：正文第 1 页实际上是 PDF 的第 15 页，只需设置偏移量为 15，后续只需输入书本上的页码即可。*
* **多级书签**：支持 `#` (一级), `##` (二级), `###` (三级) 语法。
* **实时预览**：在写入前可预览最终对应的 PDF 物理页码，防止出错。

## 🛠️ 安装与运行

### 1. 环境准备
确保已安装 Python 3.8+。

### 2. 安装依赖
在项目根目录下运行：

```bash
pip install -r requirements.txt

```

### 3. 启动应用

使用 Streamlit 启动 Web 服务：

```bash
streamlit run PDF-tool.py

```

启动后，浏览器将自动打开 `http://localhost:8501`。

## 📘 使用指南

### 模式 A：拆分 PDF

1. 上传源 PDF 文件。
2. 在文本框中粘贴目录结构（例如从 Word 或网页复制）。
```text
1 封面
5 第一章 绪论
20 第二章 核心算法

```


3. 点击 **“执行精准拆分”**，下载 ZIP 包。

### 模式 B：批量书签

1. 上传源 PDF 文件。
2. **前言区**：输入封面、版权页的绝对页码。
3. **设置偏移量**：找到正文“第 1 页”在 PDF 阅读器中显示的实际页码（例如第 15 页），填入数字框。
4. **正文区**：直接照着书本目录输入页码和标题。
```text
1 # 第一章 (程序会自动定位到 1 + 15 - 1 = 第 15 页)
10 ## 1.1 节

```


5. 查看下方预览表格，确认无误后点击 **“重构并下载 PDF”**。
