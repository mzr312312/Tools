🎯 随机间隔专注助手 (Random Interval Focus Assistant)
专注助手是一款基于 Python 开发的桌面效率工具。与传统的番茄钟（固定时长）不同，本工具采用了随机可变的工作间隔机制。这种非线性的提醒方式旨在通过不可预测的打断来保持大脑的警觉性，防止因预知休息时间而产生的“看钟”疲劳。

软件拥有基于 ttkbootstrap 的现代化界面，支持系统托盘后台运行、详细的数据日志记录以及完全自定义的声音/视觉通知。

✨ 核心功能
⏱️ 随机间隔机制 (Randomized Intervals)：

工作时长不是固定的（如 25 分钟），而是在您设定的最小值和最大值之间随机生成（例如 3 到 5 分钟之间）。

模拟“心流”检查，让您在不知道下一次休息确切时间的情况下保持专注。

🔔 多维提醒系统：

视觉通知：调用操作系统原生通知 (Toast)，由 plyer 库支持。

听觉通知：支持自定义 .mp3 或 .wav 提示音，分别用于“休息开始”、“工作开始”和“会话结束”，由 pygame 混音器支持。

📉 自动化日志：

自动将每次会话的日期、起止时间、实际专注时长和休息次数记录到 CSV 文件中，便于量化分析效率。

🖥️ 系统托盘集成：

点击窗口关闭按钮（X）不会退出程序，而是最小化至系统托盘，保持后台计时，并在任务栏图标右键菜单中提供控制选项。

⚙️ 高度可配置：

通过内置的设置面板，可以实时调整总时长、随机区间范围、休息时长以及开关各类通知。
